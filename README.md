# 🎲 遊戲抽獎機率驗證系統 (Gacha Probability Validator)

這是一個基於 Python 與統計學假設檢定 (Hypothesis Testing) 開發的抽獎機率驗證工具。
本系統旨在幫助玩家透過實際的抽獎數據，以科學、客觀的統計學方式，驗證遊戲官方公告的機率是否屬實，並提供玩家個人的「幸運度」評鑑。

## ✨ 核心功能

* **📊 科學機率驗證**：利用常態分佈與 Z 檢定，計算在給定「顯著水準 (α)」下的合理中獎次數波動範圍。
* **🍀 玩家幸運度檢視**：不僅抓造假，也能根據 Z 分數 (Z-score) 評估玩家本次抽獎是「歐皇」還是「非酋」。
* **🔄 動態標準調整**：當系統判定機率異常（過低或過高）時，提供互動式提示，允許使用者即時放寬或縮緊檢測標準 (α 值) 進行二次驗證。
* **🧩 模組化架構**：採用 MVC 概念，核心計算邏輯 (`GachaStats.py`) 與介面流程 (`main.py`) 完全分離，未來可無痛升級為圖形化介面 (GUI)。
